# Assignment 1 – Personal Portfolio API

This project is a RESTful API built using Node.js and Express.

## How to run locally

1. Install dependencies:
npm install

2. Start the server:
npm start

Server runs at:
http://localhost:3000

## API Endpoints

### GET
/api/profile  
/api/about  
/api/projects  

### POST
/api/contact  

Example POST body:
{
  "name": "John",
  "email": "john@email.com",
  "message": "Hello!"
}

## Technologies Used
- Node.js
- Express.js
